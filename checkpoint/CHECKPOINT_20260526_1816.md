## Decisões técnicas

| Decisão | Motivo |
|---------|--------|
| Hono (não Next.js API routes) | API dedicada, deploy Railway, desacoplada do frontend |
| Tailwind v3 (não v4) | shadcn/ui incompatível com v4 |
| AuthProvider em contexto (não hook standalone) | Evitar múltiplos listeners onAuthStateChange |
| `vi.doMock` + `vi.resetModules` | Isolamento correto para módulos que leem env em import-time |
| `church_id` sempre do JWT | Segurança: nunca aceitar church_id do body |
| `churches_select` policy em 002 | Forward reference: profiles não existe em 001 |
| `InviteStatus` em português | Consistência com restante do domínio (ativo/inativo/pendente) |
| guard lazy em `getJwks()` | Evitar erro em import-time nos testes |
| redirect-to pattern no login | Preservar destino original após autenticação |
